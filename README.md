# Smart Shift Sync v1.8.4

勤務先のポータルサイトからシフト情報を自動取得し、Googleカレンダーへの同期や給与概算、連続勤務のチェックを行うためのデスクトップアプリケーションです。

## 主な機能

- **ポータル自動取得**: 勤務先専用のポータルにログインし、スケジュール情報をスクレイピングします。
- **Googleカレンダー同期**: 解析したシフトをワンクリックでGoogleカレンダーに一括登録します。
- **勤務分析・可視化**: 
  - 設定した連続勤務制限（6連勤/7連勤など）を超過した場合にカレンダー上でアラート表示。
  - 深夜手当や休日手当を算出した給与概算の表示。
- **モダンなUI**: `ttkbootstrap` を採用し、直感的で使いやすいインターフェースを提供します。
